# L2 *(working title)*

**L2 - Legends deserve to live on**

L2 is a multiplayer team-based shooter. It is a ground-up rebuild of an older, abandoned FPS from the Might & Magic era.

> **Status:** early development, pre-alpha. Not playable by the public yet.
> Follow along in the [dev diary](https://nerseus.github.io/L2-Game/).

## Highlights

- **Six classes.** Archer, Druid, Heretic, Paladin, Sorceress and Warrior.
- **43 weapons**: Bows that rain down fire, crossbows that home in, hammers that create earthquakes, wands that shoot lightning, and so much more.
- **First and third person**, switchable on the fly.
- **Modern multiplayer netcode**, built for fast, responsive fights.

## How the site works

The site is built with [Jekyll](https://jekyllrb.com/) and the
[Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) theme. Every push to `main`
runs the **Build and Deploy** GitHub Action (`.github/workflows/pages-deploy.yml`), which
turns the Markdown files into the website and publishes it to GitHub Pages. Nothing has
to be generated by hand.

| Where | What |
|---|---|
| `_posts/` | Dev diary posts, one Markdown file each: `YYYY-MM-DD-slug.md` |
| `_drafts/post-template.md` | Copy this to start a new post |
| `_tabs/` | The sidebar pages: The Game, Roadmap, About (plus Categories, Tags, Archives) |
| `assets/img/` | Site images. Post images go in `assets/img/posts/` |
| `_config.yml` | Site title, tagline, author, avatar and theme settings |

Adding media to a post:

```markdown
![A Paladin firing a crossbow](/assets/img/posts/2026-10-02-crossbow.png)

{% include embed/youtube.html id='VIDEO_ID' %}
```

To preview locally (needs Ruby): `bundle install`, then `bundle exec jekyll serve`, and
open <http://127.0.0.1:4000/L2-Game/>.
